# Проблемные места

- Судя по всему, основным источником проблемы является MES. Рассчет идет 2-3 мин, а большие заказы до полу-часа. 
Ожидается, в среднем +100 заказов ежемесячно, а это + 200/300 минут минимум к ожиданию. Конечно же очередь растет. 
К этому прибавим открытое API для продавцов.

- Так же имеется проблема с первой страницей MES. Больше заказов - больше нагрузка. По видимому система не успевает отвечать.

- Судя по схеме - оба приложения монолиты, с монолитной БД.

- MES написан на Vue и C#, но компетенции больше в React и Java. Это моэет влиять на понимание узких мест в технологиях.
  Так же всего один тестеровщик и devops. 

# Решения 

- В первую очередь необходимо вертикальное масштабирование. Увеличить колличество памяти для БД и судя по всему оперативной,
  для более быстрой обработки моделей 

- Разбить приложения на микросервисы. Для каждого сервиса своя бд. 
  MES разбить на 3 сервиса - расчет модели, список заказов, работа по конкретному заказу
- Судя по схеме, данные перетягиваются из сервиса к сервису через api, что создает доп нагрузку. Нужна единная БД для, в которую могут стучать
  и CRM и MES. Необходимо разбить на шарды.
- Настроить кэш для просмотра магазина и каталогов. Это поможет ускорить загрузку. Создать реплики. 
- Нанять хотябы по одному react и java разработчиков для переписывания на микросервисы + выявления и оптимизации узких мест. Так же нанять 
  тестировщиков, по сути у нас проектов 2 и работы много. Devops тоже нужен, тк настройка микросервисов, кэширования и тд - все это требует 
  времени и компетенции
- Настроить метрики, логирование, трейсинг - все это нужно для выявления ошибком и узких мест системы

# Цель 

- Приложения разбиты на микросервисы
- Грамотно выстроеная БД, каждые микросервис ходит в БД напрямую 
- Насторены метрики, как со стороны фронтенда, так и для бэкэнда
- Оптимизированные приложения под нужные платформы

Если брать первые 3 пункта 

1 - увеличить мощности (память и тд)
2 - настройка кэша 
3 - снизить нагрузку путем разбивки БД и прямого дуступа сервисов к ней.
