# Анализ 
В первую очередь логи требуются в следующих системах:
- Internet Shop
- CRM
- MES

INFO: 
- Изменение статуса заказа. Логируем время, id пользователя, номер заказа.
- Заказы по пользователю. Логируем время, id пользователя, номера заказа, статусы
- Загрузка 3d модели. Время, объем файла, id пользователя, номер заказа, кол-во файлов, отмена операции
- Создание 3d модели. Время, объем файла, id пользователя, номер заказа, отмена операции
- Заказов, взятые в работу оперетором. Id оператора, номер заказа, время 
- Изменение статуса заказа оператором. Id оператора, номер заказа, время, статус 

Так же, как минимум стоит внедрить FATAL и ERROR - для выявления и аналитики критических мест

# Мотивация

Логи стоит внедрить для отладки технической части приложений. 
С точки зрения бизнеса - это сбор данных для последующей аналитики
Как было выше сказанно, внерить логи стоит в следующие сервисы:
- Internet Shop
- CRM
- MES

Влияние метрик:
- Статусы запросов - понимание того, какие запросы и как часто ломаются, какие нет 
- Объем загружаемых файлов - полезно как для бизнеса, так и стехнической стороны
- Заказы по пользователю. Бизнес может выстроить аналитику по пользователям, которые возвращаются или наоборот
- Статусы заказов - понимание того, как много заказов доведенно до конца, какие отвалились и на каком этапе 
- Обработка заказа оператором. Понимание работы операторы, выявление тех или инных проблем, связанных с работой заказа со стороны оператора
